ItTalksTTS — Windows install
============================

  >>> Double-click ItTalksTTS-Setup.exe <<<

Follow the wizard, then open ItTalksTTS from the Start menu or desktop shortcut.

First launch downloads Kokoro voice models automatically (internet required, a few minutes).

Cursor: hooks install automatically to your user profile (.cursor folder).
  Restart Cursor once, use Agent mode in any project — no need to clone the ItTalksTTS repo.
